# tgbotstory2 — Telegram-бот для мониторинга контента VK / Instagram* / TikTok

> *Переписывается с нуля. Предыдущая версия полностью удалена.*

## Бизнес-логика (сохранена из предыдущей версии)

Бот отслеживает новые публикации (посты и истории) указанных пользователей и пабликов в VK, Instagram* и TikTok. При появлении нового контента бот автоматически скачивает медиафайлы и отправляет их в Telegram-чат.

> \* Деятельность Meta Platforms Inc. (Instagram, Facebook) запрещена на территории РФ.

## Платформы

- **VK** — пользователи и паблики (stories + posts)
- **Instagram** — пользователи (stories + posts)
- **TikTok** — пользователи (posts + stories)

## Ключевые функции

- `/start` — главное меню
- Добавление / удаление целей мониторинга
- Загрузка токенов авторизации
- Периодический опрос платформ (APScheduler)
- Дедупликация контента через хеши
- Доставка медиа в Telegram (фото/видео/группы)
- Шифрование учётных данных (Fernet)
- Логирование (structlog)
